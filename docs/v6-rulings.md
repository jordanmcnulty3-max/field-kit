# v6 rulings

Decisions made during the v6 Emergency rebuild without stopping to ask, in order. Each line: what was decided, why, and what it costs if wrong. Ruling 32 was superseded: Jordan asked for the patient-log fix before release (rulings 34 to 37). The CPR-click part of ruling 33 was also fixed then.

1. Task 4 two-tap test sets advAck=true first — the acknowledgement is one-time by spec 7.3a, so it is not a per-protocol tap — if wrong, advanced items are 3 taps on first use only.
2. validator rejects protocol ids `tool`, `report`, `all` and step ids `all` — router grammar would be ambiguous — costs nothing.
3. models — code implementers sonnet, content implementers opus (medical accuracy + web research), code reviewers sonnet, content reviewers opus, final review opus.
4. add protocol field `draft: true` = content not yet source-checked; draft protocols omit source url/year; validator warns per draft; `build.py --release` fails if any draft remains — gives a hard gate that unverified medical content cannot ship — costs one flag.
5. a running CPR coach survives closing the overlay and navigation (like TQ timers); it stops only by an explicit two-step Stop; home strip shows it — a silent stop mid-arrest is the worst failure of this tool — costs a little state complexity.
6. my dispatch said 44px for burn regions; the Global Constraint (56px in Emergency) wins — spec is binding — costs a taller figure (stack front and back).
7. lone adult rescuer off-grid — state AHA's advice (activate first) and the off-grid trade-off in the step, and record as an open question for Jordan; do not pick silently.
8. chest-thrust technique restored from MedlinePlus (nih.gov, a preferred domain in the guide), attributed as outside the AHA/Red Cross tier, Mayo landmark disagreement recorded as an open question — an untrained rescuer with no how-to is worse than a sourced NIH description — if wrong, Jordan can swap after medical advice.
9. organs exception goes into s3 and s11 as `warn` plus a clause in s3's action text, not a new question at step 2 — the common severe limb bleed must not gain a tap; a warn is shown prominently on the step — if wrong, someone reads the warn a second late.
10. over-the-counter pain medicine named without a dose is allowed where the AHA 2024 first aid guideline recommends it to lay responders — it is lay-level guideline content — spec 7.3 list of four medicines was illustrative; record in the design doc at release.
11. author may make the one-line cross-batch edit to recovery-position s5 (spine roll for vomiting/choking on blood, MedlinePlus + Mayo) — consistency between protocols outranks batch boundaries.
12. impaled-object — add a superficial-fishhook branch from MedlinePlus; the airway-blocking exception (Oregon EMS manual, below authority tier) goes in detail with attribution plus an open question — silence on an object blocking the airway is worse than an attributed lower-tier statement.
13. frostbite rewarming water = the overlap of AHA (37-40 C) and WMS 2019 (37-39 C): 99 to 102 F (37 to 39 C) — inside both sources' ranges so neither is contradicted — recorded as an open question; if wrong, slightly narrower than AHA allows.
14. chemical eye exposure in poisoning is sent to the Eye injury protocol by title (one source of truth) — two protocols giving different rinse/evacuation rules for the same splash is the defect — open question recorded.
15. many-stings — symptom-based evacuation on the "no" branch (sourced, poison.org) plus a lower group threshold ("dozens of stings, or any child with multiple stings"), labelled a judgement with an open question.
16. stroke signs + known diabetic on insulin or pills + fully awake + swallows safely + no meter -> give sugar per the Low blood sugar protocol (Red Cross: if unsure, give sugar) AND keep evacuating as a stroke — a treatable mimic must not be withheld sugar; no opened source says nothing-by-mouth for stroke — open question recorded.
17. a real faint follows AHA 6.8 / Red Cross (get help); any off-grid narrowing is Jordan's call via open question, not the app's.
18. traction-splint.json is removed (TCCC dropped the skill in 2024; no top-tier source gives steps; plan says leave out what sources do not describe); traction-splint/sager/hare keywords added to fracture.json so search lands on Broken bone; open question for Jordan. This drops one item from the design's advanced list — tell Jordan.
19. tourniquet repositioning — the 6-hour question is asked BEFORE any step that loosens a tourniquet (conservative); TCCC's silence on a reposition time limit recorded as an open question — reperfusion off-grid with no monitoring is the worse error.
20. author may make cross-batch edits needed for exact-title cross-references (bleeding, chest-wound, march) and keywords (fracture).
21. s26y keeps 'do not try conversion again' as the app's labelled caution (leaving a working tourniquet on is the conservative error), with TCCC's retry allowance stated in the detail and an open question.
22. step body order is action, warn, figure, list controls (light outline row, not fixed chrome), detail — the action must be the first and heaviest thing on the screen (spec anti-goal) — costs a short scroll to the controls on steps with a figure.
23. a figure that cannot be made recognisable without its caption after one redraw is removed (its `fig` line deleted) rather than shipped.
24. fix Important 1 with a router-owned history index in history.state (player leaves by index difference) plus state-preserving replace and a timeout fallback — the pushed-entry counter has now failed in three separate reviews; patching it again is the riskier path — costs a larger router change in the single fix wave.
25. `notes` are shown in the all-steps view and indexed by search (they are sourced content already reviewed); validator gets an allowed-key list and shape checks.
26. protocol-step logging — one entry per step per protocol run, with a short "Logged: …" toast — spec asked for automatic logging; duplicates and silent writes are the defect.
27. restore keeps tourniquet timers that are running on the phone (merged by id with the file's) — a restore must never delete a running tourniquet clock.
28. `advAck` is not written to backup files (a backup handed to another person must not skip the advanced-procedures warning); `proto.active` stays excluded (confirmed).
29. the six browser dialogs in Tactical code (app.js, map.js), the wake-lock/confirm/accessor consolidation, AbortSignal.timeout fallback and minimum-iOS documentation go to the phase 2 backlog — pre-existing or refactor-only; not v6 blockers.
30. fix-wave commits keep the "Claude Opus 5.5" co-author trailer — it names the model that wrote them, same as earlier opus task commits — costs nothing if wrong; amend is cheap before push.
31. build.py rejecting more than one positional argument is accepted — stricter than asked but prevents a mistyped output path being ignored — if wrong, a script passing two paths fails loudly.
